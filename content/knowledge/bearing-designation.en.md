## Read the basic code first

A designation such as **6205-2RS/C3** is not one opaque number. The basic code identifies the bearing type and dimension series; the bore code maps to nominal bore diameter; suffixes describe sealing and internal clearance.

## Decode suffixes carefully

`2RS` indicates contact seals on both sides, while `C3` identifies an internal clearance group larger than normal. A suffix is meaningful only when read with the complete designation and the applicable standard.

## Confirm the controlled drawing

Commercial descriptions cannot replace the manufacturer's controlled drawing. Confirm chamfer, cage, tolerance, marking and inspection requirements before production or maintenance procurement.
