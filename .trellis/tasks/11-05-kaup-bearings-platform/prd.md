# Kaup Bearings / 北轴汇垂直 B2B 平台

## Goal

在 `https://kaupbearings.com` 交付一个中英双语、可从首版建立搜索基础的轴承行业垂直 B2B 前端平台。专业采购人员应能按轴承结构、尺寸、型号和工况发现产品与供应商，并完成产品发布、RFQ 询价、询盘查看与供应商回复的完整演示闭环。

## Background

- 英文品牌为 `Kaup Bearings`，中文工作品牌为 `北轴汇`。
- 信息架构和交互广度参考 `kaup-link`，但视觉、分类、内容和专业术语必须面向轴承行业重新设计。
- 技术栈采用 `kaup-ai-website` 的 Nuxt 4 + TypeScript + Nuxt UI + Tailwind CSS + Nuxt Content + Nitro，而非复制其 AI 官网业务或部署拓扑。
- 首版是可交互前端原型：真实数据替换前使用本地演示数据与浏览器存储，不提供真实认证、邮件通知或文件上传。

## Requirements

### R1 分类与专业参数

- 提供 8 个一级分类：球轴承、滚子轴承、直线运动、滑动轴承、轴承单元与轴承座、回转支承与特种轴承、轴承零部件、安装润滑与检测。
- 二级分类覆盖深沟球、角接触球、调心球、推力球；圆柱/调心/圆锥/滚针/推力滚子；直线球轴承、直线导轨、丝杠支撑；轴套、关节轴承、杆端、止推垫片；外球面/带座/法兰/滑块单元；回转支承、剖分、陶瓷混合、高温耐腐蚀；钢球/滚子/保持架/套圈/密封；安装工具/感应加热/润滑/状态监测。
- 产品参数使用 `d`、`D`、`B/T`、`Cr`、`C0r`、极限转速、精度等级、游隙、密封/防尘、保持架、材料和标准等专业字段。
- 精度以 ISO/DIN 记号为主，并提供 ABEC 对照说明；支持 `C0/CN/C3/C4` 等游隙术语。

### R2 商品与供应商目录

- 首批包含 32 件专业演示商品、每类 4 件；12 家演示供应商。
- 首页优先提供分类导航与型号/尺寸搜索。
- 商品目录支持类型、子类、型号/关键词、尺寸范围、精度、游隙、密封、保持架、材料、认证、应用行业和供应商筛选。
- 筛选状态可通过 URL 分享；数值范围包含边界；空结果提供可恢复状态。
- 商品详情页展示技术描述、完整参数、认证、供应商、应用、相关商品和 RFQ 入口。
- 供应商详情页展示企业类型、主营类别、制造工序、质量体系、检验能力、精度能力、应用行业、出口市场和交期。
- 所有演示商品、供应商、价格、证书和库存信息必须清晰标注为 Demo，不得伪装为真实数据。

### R3 采购与供应商工作流

- 提供买家、供应商两种演示角色及独立登录/注册入口。
- 新注册供应商状态为 `pending`，可以编辑资料和保存草稿，但不可发布商品或回复询盘。
- 通过明确标注的“模拟审核通过”后，供应商可发布商品并回复询盘。
- 预置至少一个已验证演示供应商账号，用于演示完整流程。
- 商品发布支持双语标题与描述、分类参数、认证、贸易条款、图片文件名预览、草稿恢复和校验。
- RFQ 支持具体商品询价及通用询价，采集公司、国家、型号/尺寸、数量、年需求、应用、载荷、转速、精度、游隙、密封、交期和贸易条款。
- 附件仅作为演示占位，不声称已经上传或发送。
- 询盘状态严格为 `submitted → viewed → replied`；买家可在 My Inquiries 查看回复，供应商可在 Inbox 查看、标记已读并回复。
- 浏览器存储失败时必须明确报错，不得显示虚假成功。

### R4 技术内容与产业内容

- 提供独立“选型与技术中心”，至少覆盖型号命名、精度等级、游隙、密封/防尘、保持架、安装配合和失效分析。
- 提供轴承应用行业、行业资讯和展会内容；演示资讯与展会详情不得冒充真实新闻。
- 技术内容使用专业术语和合理的内链，避免关键词堆砌。

### R5 SEO

- 正式 canonical 域名为 `https://kaupbearings.com`。
- 英文使用根路径，中文使用 `/zh/` 路径；双语页面互相声明 `hreflang`。
- 分类页与商品页使用可读静态路径，不使用 `product.html?id=...` 形式。
- 首页、分类页和技术知识页允许索引；演示商品、供应商、资讯和展会详情使用 `noindex,follow`。
- 筛选、搜索、排序、登录和工作台页面不进入 sitemap；筛选页 canonical 到对应分类页。
- 服务端返回的初始 HTML 必须包含页面标题、H1、正文、规格和内部链接。
- 提供逐页 title/description、canonical、Open Graph、Twitter card、`robots.txt`、`sitemap.xml` 和真实适用的 JSON-LD。
- 图片提供明确尺寸、响应式资源和合理加载优先级，避免 CLS 并优化 LCP。

### R6 视觉与图片

- 视觉为精密工业 B2B 风格：石墨黑、钢灰、冷蓝和克制安全橙，高信息密度但保持可读性。
- 图标使用一致的矢量图标库，不使用 emoji 作为结构图标。
- 所有图片为写实摄影风格，不使用插画、卡通、动漫、塑料感 3D 渲染或不合机械常识的轴承结构。
- 场景图片与产品微距结合；无故意虚构的品牌、包装、证书或无法核实的工厂。
- 若出现人物面部，人物必须是中国籍、具有中国东北地区真实面部特征；禁止外国人、其他亚洲国家或泛亚裔“通用面孔”。
- 已确认三张样张方向可用，其中风电检修样图必须使用修正后的中国东北技术人员版本。

### R7 可访问性与响应式

- 适配 375、768、1024 和 1440 像素视口，不出现横向滚动。
- 文本对比度达到 WCAG AA；可见焦点、键盘导航、跳转主内容链接和 44px 触控目标完整。
- 表单使用可见标签、字段级错误和状态反馈；弹层可键盘关闭并正确管理焦点。
- 尊重 `prefers-reduced-motion`；动态内容不造成不可控自动轮播。

### R8 许可证

- 项目采用与 `kaup-ai-website` 相同的 **Dalian Kaup Technology Co., Ltd. Proprietary License**。
- 仓库必须为私有包：`package.json` 设置 `"private": true` 和 `"license": "UNLICENSED"`。
- 根目录提供 `LICENSE` 专有许可文本，并在 README 中注明代码与内容归 Dalian Kaup Technology Co., Ltd. 专有。

## Out of Scope

- 不部署到域名、不修改 DNS、不配置生产托管或搜索引擎后台。
- 不实现真实身份认证、真实支付、真实库存、真实文件上传、邮件发送、供应商审核后台或生产数据库。
- 不抓取真实厂商商品或伪造可成交报价。
- 不复制 Kaup AI 官网的业务定位、品牌视觉或双域/ICP/relay 部署结构。
